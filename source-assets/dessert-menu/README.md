# Dessert menu assets
Final illustrations generated with the built-in image_gen tool from the user-supplied cartoon menu reference.
Prompt: preserve the nine reference cake illustrations as a transparent 3x3 atlas; remove all text/background; mirror honey and lemon wedges so their tips face left like dark chocolate; warm brown outlines, glossy simplified hand-drawn cartoon food, tiny attached contact shadows.
Atlas rows, left to right: honey / lemon / dark; pistachio / strawberry / cookie; London / Ferrero / pistachio-strawberry.
Original PDF preserves classic products, additions and footer. The build script adds currency, fixes leader dots and appends illustrated cakes.
Build: python tools/build_dessert_menu.py
Final PDF: output/pdf/Dolce_Dessert_Menu.pdf
